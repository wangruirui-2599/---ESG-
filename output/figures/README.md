# ESG Insight Valuator - 可视化图表说明

本目录包含 ESG Insight Valuator 系统生成的所有可视化图表文件。这些图表覆盖了从单个公司ESG评分到行业对比分析的全方位视觉呈现。

## 图表分类概览

### 1. 单个公司ESG雷达图 (`esg_radar_*.png`)
- **文件模式**: `esg_radar_600001.png`, `esg_radar_600002.png`, ... (共10个文件)
- **生成函数**: `plot_esg_radar()` (`src/reporting/visualizer.py`)
- **图表说明**: 
  - 展示单个公司在环境(E)、社会(S)、治理(G)三个维度的评分
  - 雷达图形式，评分范围0-100分
  - 包含股票代码和行业信息标注
- **解读要点**:
  - 雷达面积越大，ESG综合表现越好
  - 三个维度的均衡性反映公司ESG结构的稳定性
  - 可与同行业其他公司雷达图对比分析

### 2. 异常概率分布直方图 (`anomaly_distribution.png`)
- **生成函数**: `plot_anomaly_distribution()` (`src/reporting/visualizer.py`)
- **图表说明**:
  - 展示整个股票池的财务异常概率分布情况
  - 直方图形式，将异常概率(0-1)分为30个区间
  - 用不同颜色标注风险等级区域:
    - 绿色: 低风险 (<0.2)
    - 黄色: 中等风险 (0.2-0.4)
    - 橙色: 中高风险 (0.4-0.6)
    - 橙红色: 高风险 (0.6-0.8)
    - 红色: 极高风险 (>0.8)
- **解读要点**:
  - 分布右偏表示高风险股票较多
  - 均值和中位线显示整体风险水平
  - 可识别异常概率集中的风险区间

### 3. 行业ESG总分排名图 (`industry_esg_ranking.png`)
- **生成函数**: `plot_industry_esg_ranking()` (`scripts/generate_industry_reports.py`)
- **图表说明**:
  - 横向柱状图展示各行业ESG总分排名
  - 每个行业的柱状图分解为E、S、G三个子柱
  - 按ESG总分从高到低排序
  - 标注每个行业的具体分数
- **解读要点**:
  - 快速识别ESG领先行业和落后行业
  - 分析各行业内E、S、G维度的不平衡性
  - 行业间ESG表现差异程度

### 4. 行业ESG时间序列对比图 (`industry_esg_timeseries.png`)
- **生成函数**: `plot_esg_timeseries_comparison()` (`scripts/generate_industry_reports.py`)
- **图表说明**:
  - 折线图展示各行业2019-2024年ESG总分变化趋势
  - 每个行业一条折线，用不同颜色区分
  - 显示行业ESG表现的动态演变
- **解读要点**:
  - 识别ESG改善趋势明显的行业
  - 发现ESG退化的风险行业
  - 分析行业ESG表现的收敛或分化趋势

### 5. 行业风险传导热力图 (`industry_contagion.png`)
- **生成函数**: `plot_contagion_heatmap()` (`scripts/generate_industry_reports.py`)
- **图表说明**:
  - 左右两个子图构成的组合图
  - 左图: 各行业传导风险评分条形图
  - 右图: 各行业受影响上游行业数量条形图
  - 颜色编码表示风险等级(绿→黄→红)
- **解读要点**:
  - 传导风险评分高的行业容易受其他行业波动影响
  - 受影响行业数多的行业在产业链中处于下游位置
  - 识别系统性风险的关键传导节点行业

### 6. 行业ESG维度雷达对比图 (`industry_multi_radar.png`)
- **生成函数**: `plot_multi_industry_radar()` (`scripts/generate_industry_reports.py`)
- **图表说明**:
  - 将多个行业的ESG雷达图叠加在同一坐标系中
  - 每个行业一条闭合曲线，显示其在E、S、G三个维度的表现
  - 不同行业用不同颜色区分
  - 包含图例说明各行业对应的曲线
- **解读要点**:
  - 直观比较不同行业在ESG三个维度上的相对优势
  - 识别行业特有的ESG结构特征(如某行业在G维度特别突出)
  - 发现行业间ESG表现的相似性和差异性

### 7. 行业投资吸引力矩阵 (`industry_attractiveness.png`)
- **生成函数**: `plot_industry_attractiveness()` (`scripts/generate_industry_reports.py`)
- **图表说明**:
  - 散点图，X轴为ESG总分，Y轴为期望上行空间(%)
  - 以ESG总分60分和上行空间0%为分界线，形成四个象限
  - 每个行业一个散点，气泡大小表示市场关注度
  - 异常概率高的行业用红色虚线圆圈标注
- **四大象限**:
  - 高ESG+正回报(右上): 绿色，推荐配置
  - 低ESG+正回报(右下): 橙色，谨慎乐观
  - 高ESG+负回报(左上): 蓝色，防御型
  - 低ESG+负回报(左下): 红色，规避
- **解读要点**:
  - 综合ESG表现和估值吸引力的二维分析
  - 识别既有良好ESG又有上行空间的"黄金行业"
  - 发现ESG表现好但估值过高的行业

### 8. 行业ESG动量气泡图 (`industry_momentum_bubble.png`)
- **生成函数**: `plot_esg_momentum_bubble()` (`scripts/generate_industry_reports.py`)
- **图表说明**:
  - 散点图，X轴为ESG总分，Y轴为ESG动量分数
  - 气泡大小与财务健康度成反比(异常概率越低，气泡越大)
  - 颜色编码表示动量方向:
    - 绿色: 强劲正动量 (>0.03)
    - 浅绿: 温和正动量 (0-0.03)
    - 灰色: 稳定 (-0.02-0)
    - 红色: 负动量 (< -0.02)
- **解读要点**:
  - ESG总分反映当前水平，动量反映变化趋势
  - 大气泡表示财务健康、风险低的行业
  - 识别"高质量改善型"行业(高总分、正动量、大气泡)

## 图表生成流程

这些图表是通过以下脚本生成的:

1. **主要生成脚本**: `scripts/generate_industry_reports.py`
   - 调用所有行业分析图表的生成函数
   - 生成行业对比分析报告

2. **可视化模块**: `src/reporting/visualizer.py`
   - 包含基础图表生成函数
   - 提供ESG雷达图、异常分布图等单公司图表

3. **生成顺序**:
   - 首先加载处理后的数据(`data/processed/`)
   - 然后依次生成各类图表
   - 最后整合到HTML报告中

## 使用建议

### 投资决策应用
- **行业配置**: 使用行业排名图和吸引力矩阵筛选目标行业
- **风险控制**: 参考异常分布图和风险传导图管理组合风险
- **趋势跟踪**: 通过时间序列图和动量图把握ESG演变趋势

### 研究分析应用
- **行业比较**: 利用雷达对比图和多图表综合分析行业特征
- **因子分解**: 通过E/S/G分解图理解行业ESG结构
- **动态监测**: 定期生成图表序列，跟踪ESG表现变化

## 技术说明

- **图表格式**: PNG格式，150 DPI分辨率
- **颜色方案**: 使用系统统一的调色板(`COLOR_PALETTE`, `ESG_COLORS`)
- **中文字体**: 自动检测并配置中文字体，确保中文正常显示
- **尺寸标准**: 主要图表尺寸为(12, 7)英寸或(14, 8)英寸
